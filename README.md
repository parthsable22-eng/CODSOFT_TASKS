# CODSOFT Data Analytics Internship

This repository contains the projects completed during my CodSoft Data Analytics Internship.

## Tasks Completed

### Task 1 - Data Cleaning and Preprocessing
Imported, inspected and cleaned a sales dataset using Python and Pandas.

### Task 2 - Exploratory Data Analysis
Performed descriptive statistical analysis to identify trends, distributions, relationships and outliers.

### Task 3 - Data Visualization
Created visualizations using Matplotlib and Seaborn to communicate important findings.

### Task 4 - Customer Data Analysis
Analyzed customer purchasing behavior and segmented customers based on spending and demographic characteristics.

### Task 5 - Web Data Extraction and Analysis
Collected publicly available book information using Requests and BeautifulSoup and performed exploratory analysis.
